# 象棋协作工作台

面向 CS109 中国象棋课程项目的双人网页工作台：编辑 Java、运行真实 Swing 窗口、提交验证、协作讨论与项目问答。

课程项目独立维护于 `SUSTech-CS109-XiangQi`，可下载后直接导入 IntelliJ IDEA。工作台只承担辅助开发与协作。

首轮支持两路独立运行会话、两个正式账号和两个隔离测试账号。

入口：<https://124.221.144.155/xiangqi/>。邀请码单独保存在本机受限目录，不进入源码仓库。网页平台与 Java 游戏账号分开：邀请码登录协作平台，游戏内注册用于课程要求的对局存档。

## 日常使用

1. 输入自己的邀请码。右侧打开 Main 或其他源文件，编辑会自动保存到个人草稿；`Ctrl+S` 可立即保存。
2. 点击“运行”。左侧编译并运行同一份 Java 源码，鼠标可直接操作 Swing 窗口。“放大”进入全屏，Esc 返回；“停止”释放运行资源。
3. Java 索引就绪后，输入 `board.` 可获得真实对象成员，`(` 触发参数提示，F12 跳转定义。编译错误和运行日志在左下方。
4. 点击“提交共同版本”才启动 CI 和三方合并；自动保存不会改变同伴的草稿。对方点击“同步共同版本”接收已合并内容。
5. “下载 ZIP”导出完整 Maven 项目；在 IDEA 打开其中包含 `pom.xml` 的目录。离线修改后连同 `.xiangqi-studio.json` 一起打包上传，平台可识别共同基线。
6. 留言区可写普通消息；选择代码行并点击“批注选中行”可绑定原文，再通过“提醒”选择同伴。被 @ 的人再次登录时能看到未读计数和对应批注。

项目问答会读取当前已保存的完整 Java、Markdown 和 XML 快照以及最近对话，再发送一次 DeepSeek 请求。它没有工具、不会执行操作或改代码；每个账号的对话记录独立。编辑后发问会先保存，所以回答对应当前草稿。

## ZIP 与冲突

上传只创建候选。候选 CI 通过后，平台尝试与共同版本合并，再运行一次最终结果 CI，全部通过才更新共同版本。CI 包括 Maven 测试，以及镜像内不可由上传替换的课程测试副本。

同一行冲突时，共同版本、上传候选和个人草稿都保留。版本页可查看文本差异、日志并下载候选。先与同伴讨论，再点击“保留草稿并处理冲突”，从共同版重新编辑、提交。该操作会把此前服务器草稿留为私人版本，本机未同步内容也可通过“导出本机恢复稿”下载。

同一账号打开两个编辑页时，旧页面的保存不会覆盖较新的内容；它会创建私人冲突候选。只有明确点击“提交此版本到共同区”才把它提交到协作区。

没有基线标识的外部 ZIP 仍运行 CI，但保留为待选择基线的候选。选择基线表示你确认该 ZIP 基于这个共同版本修改，随后重新校验和合并。缺少的文件会保留，上传不会被解释为批量删除。

ZIP 上限 25 MiB，展开后上限 100 MiB / 2000 个文件，单文件 10 MiB。不要放入 `.git`、`.idea`、`target`、账号存档、密钥、运行二进制或嵌套压缩包；不允许链接、路径越界及 Windows 大小写冲突的文件名。

## 代码结构

| 部分 | 实现 |
|---|---|
| `web/main.ts` | 页面、Monaco 编辑、异步保存、版本与留言交互、noVNC 画面 |
| `web/lsp.ts` | Monaco 与标准 LSP 的补全、参数提示、定义及诊断连接 |
| `studio/app.py` | 登录、CSRF、项目 API、项目问答、WebSocket 转发 |
| `studio/store.py` | SQLite 账号/消息记录、Git 快照、路径校验、ZIP 和草稿冲突 |
| `studio/workflow.py` | 串行 CI、候选校验、三方合并及合并结果校验 |
| `studio/runtime.py` | 两路会话限制及隔离容器管理 |
| `runner/runner.py` | 容器内 Maven、真实 Swing/Xvfb、VNC 和 JDT LS |

Java 学习与展示主要阅读独立课程仓库中的 `docs/代码导读.md`。平台没有混入课程项目的源代码包。

## 运行边界

- 同时最多两个账号使用运行 / 语义服务。两个正式账号在正式协作区，两个测试账号在测试协作区；两组的共同版本、留言及数据互不混用。
- 每个账号拥有私人源码草稿、Java 进程、对局文件、索引缓存和聊天记录。普通留言及主动提交的候选在同一协作区共享。
- 关闭页面后运行进程可能保留以便重新连接；不用时点击“停止”或“退出”，释放会话。一个账号同时只开一个语义编辑会话。
- 容器没有网络，不获得 DeepSeek 密钥、Docker 接口或其他账号的目录。GUI 和 CI 各限制 384 MiB，JDT LS 限制 512 MiB，CI 串行执行。
- 网页端支持现有 JDK / 测试依赖。新增第三方依赖需先更新隔离镜像的离线缓存，不能在运行容器里联网下载。
- 当前提供编译日志和语义诊断，没有断点调试。网页编辑协作也不等同于游戏内联网对战；后者列入课程的进阶 Spec。
