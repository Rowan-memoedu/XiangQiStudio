# 功能验证

## Java 课程项目

课程项目共 29 个交付文件，入口为 src/Main.java；model 下按 piece、board、game 分类。Board 保存布局，Game 管理对局，Move 保存一步走棋。课程 README、代码导读和进阶 Spec 只包含象棋项目内容，没有工作台代码、平台标识文件或本机盘符配置。

25 项 Java 测试通过：14 项规则、7 项账号与存档、1 项数据目录配置、1 项快照与合法走法扩展入口、2 项绘制与点击交互测试。包含窗口放大后的点击定位验证。服务器新运行镜像及迁移后的共同版本也通过课程测试和可信测试副本。

下载 ZIP 解压到另一处含中文的目录后，使用 JDK 25 和 Maven 独立完成测试、编译及 JAR 打包。服务器实际运行了 Main 图形界面。IntelliJ IDEA 的人工导入体验仍由用户试用确认。

## Java 补全

两名测试用户分别连接真实 JDT LS，均获得 45 个成员候选，包含 tryMove 和 isInCheck；参数提示与真实方法签名一致，定义跳转指向 src/model/game/Game.java，不存在的方法产生语义诊断。

## 选中代码与完整回答

“选中当前行”选择文件和行号，可转入批注或提问。“解释选中程序”向服务器发送当前选择范围，再从已保存源码解析原文。

真实 DeepSeek 请求围绕 Main 中创建 Game 的选中行返回了 2,139 字符，结束标记为 stop。另用 21,106 字符的模拟回答验证全文渲染、独立滚动到最后一段及展开阅读。模拟内容没有写入服务器聊天记录。

后端自动测试验证了超长回答在长度限制后接续、完整拼接，以及供应商流中断不能被标记为正常完成。旧聊天没有被改写；新增回答保存全文和结束状态。

## 协作、CI、ZIP 与讨论

25 项平台自动测试通过。新版真实服务器另行验证：

- 两账号异步保存私人草稿，不相互覆盖。
- 无冲突修改经过候选 CI、三方合并、合并结果 CI 后进入共同版本。
- 同一行修改冲突时共同版本不变，多个候选保留并可下载。
- Java 编译失败阻止合并，候选和错误日志保留。
- 带版本注释的 ZIP 上传经过真实 CI 后合并。
- 缺少可靠基线的 ZIP 即使 CI 通过，仍保留待选择基线的候选。
- 行批注保留原文，被 @ 用户离线再登录后收到提醒，已读状态持久化。
- DeepSeek 根据当前项目回答，聊天记录按账号隔离。
- 中断的 CI 可重试；数据库连接及时关闭；语义服务启动失败会释放会话预约。

登录、跨账号/跨协作区访问、CSRF、ZIP 路径越界、符号链接、Windows 文件名及大小写冲突均有自动检查。测试只写入测试协作区。
