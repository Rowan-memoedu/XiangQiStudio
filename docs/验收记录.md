# 功能验证

## Java 课程项目

课程源代码 ZIP 解压后使用 JDK 25 和 Maven 独立构建成功，22 项测试全部通过：14 项规则测试、7 项账号与存档测试、1 项点击交互测试。服务器运行镜像也通过同一套测试。

基础功能覆盖初始化、新对局、注册登录、游客限制、持久账号、独立存档、损坏检测、七类棋子规则、吃子、将军、将死、困毙、认输、双方确认和棋、回合状态与上一步显示。增强功能包括合法落点、悔棋、逐步回放、累计用时、自动存档、三个手动存档位和两种主题。

已验证标准 Maven 项目结构、解压后的编译与打包，以及实际 Main 图形界面运行；没有把这些结果记为已完成 IntelliJ IDEA 界面中的人工导入验收。

## 网页运行与补全

两名测试用户在独立 Chrome 会话中同时运行真实 Swing。实际点击红兵使其向前移动，另一账号棋局保持不变。网页编辑 Main 后自动保存，重新编译运行使棋盘背景改变；演示代码随后恢复。

Monaco 菜单显示 JDT 返回的 `tryMove`，选择补全后插入方法调用，F12 从 Main 跳转到 Board。两个账号的 LSP 测试均返回 42 个成员候选，参数提示与真实签名一致，未知方法产生语义错误提示。

浏览器一键下载已触发并保存 ZIP。两个正式账号的全部 25 个项目文件与交付源码一致，正式区未混入测试文件；各自下载包的全部项目文件逐字节核对通过。

两个 GUI 容器约各占 84 MiB，两个语义服务在一次同时运行观测中约为 383 MiB 与 424 MiB，合计约 0.95 GiB。该值是实测样本，部署仍按两路完整会话限制。

## 协作、CI 与讨论

21 项平台自动测试全部通过。真实服务器另行验证了：

- 两账号异步保存私人草稿，不相互覆盖。
- 无冲突修改经过候选 CI、三方合并及合并结果 CI 后进入共同版本。
- 同一行修改冲突时共同版本不变，多个候选保留并可下载。
- Java 编译失败阻止合并，候选和错误日志保留。
- ZIP 上传经过真实 CI 后合并；缺少可靠基线的 ZIP 即使 CI 通过仍保留待处理。
- 代码批注保留原始代码片段；被 @ 用户离线再登录后收到提醒，标记已读后状态持久化。
- DeepSeek 回答实际 Main、Controller、Board、BoardPanel 的调用关系，聊天记录按账号隔离。
- 服务重启后，中断的 CI 保留候选并标为可重试失败，不会假报通过。

登录、跨账号/跨协作区访问、CSRF、ZIP 路径越界、符号链接、Windows 文件名及大小写冲突均有自动检查。测试使用独立测试协作区，正式区仅通过正常 CI 发布课程交付文档。

## 页面与部署

检查了 320、375、414、768、1280、1440 像素布局；页面及工具按钮没有横向溢出。常用正文、弱化文字、按钮、错误状态及编辑器配色通过 WCAG 对比度计算。真实浏览器操作过程中没有页面脚本错误。

正式服务不依赖安装时的 SSH 下载代理；移除临时代理与隧道后，完整双会话运行和浏览器操作再次通过。既有站点路由保留。
