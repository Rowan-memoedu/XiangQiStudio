# 象棋协作工作台

## 交付边界

Java 课程项目独立于网页平台，沿用 JDK 25、Maven、Swing。下载的项目可直接导入 IntelliJ IDEA，运行 `Main.main()` 打开窗口。课程代码使用数组、普通类、继承、集合、文件读写和 Swing 事件，不引入应用框架。

全部基础功能包括完整初始局面、新游戏、注册登录与游客限制、账号持久化、包含回合和走棋历史的存读档、损坏存档处理、七类棋子规则、将帅安全、将死、困毙、认输、双方同意和棋、状态与上一步显示。

首轮加入合法落点、悔棋、逐步回放、计时、自动存档及简单主题。人机、联机和其他有价值的进阶方向写成方案，由用户后续决定。

## 网页编辑与运行

左侧显示服务器实际运行的 Swing 窗口，支持鼠标键盘交互；右侧是项目树、Java 编辑器和运行日志。修改后重新编译运行，左侧效果来自同一份 Java 源码。

使用成熟的 Monaco 编辑器与 Eclipse JDT LS 提供语义补全、对象成员、参数提示与定义跳转。首轮通过编译错误和运行日志排错，不含断点调试。

Markdown 支持编辑、渲染预览和左右对照，包含表格、代码块与 Mermaid 调用关系图。运行画面、代码、文件目录、日志与底部讨论通过分隔条调整大小；运行窗口跟随画面区域改变尺寸，避免外层黑框。布局按账号保存在当前浏览器。

两路完整会话是首轮并发目标。四个账号包含两个正式账号和两个测试账号；每个账号的文件、运行环境、数据和聊天独立。测试账号属于独立测试协作区，不污染正式共同版本。腾讯云部署保留现有服务。

## 保存与合并

编辑自动异步保存到个人草稿。主动提交或上传 ZIP 才进入合并流程。下载包带有共同基线标识，保留完整 IDEA 项目结构；运行数据、凭据和网页平台源码不打入课程包。

基线信息存入 ZIP 注释，解压后的项目不添加平台标识文件。导入兼容此前下载包的标识文件；重新打包导致注释丢失时仍执行 CI，并保留候选等待确认基线。

上传包先进入独立候选版本并运行 CI；三方合并没有冲突时，再验证最终合并结果。全部通过且共同版本仍等于校验基线时才原子更新。并发提交须重新计算合并和校验。测试由平台保存可信副本，上传内容不能取消验收。

冲突、构建失败和缺少可靠共同基线的 ZIP 均保留候选及原因，不覆盖当前共同版本。用户可查看差异、讨论后形成新的提交。没有共同基线的包由用户选择基线后重新校验。

## 项目问答与讨论

DeepSeek 以当前账号项目快照和已准备的结构说明回答问题；源码改变后刷新快照。一次请求携带上下文，不让模型调用工具或自主修改代码。回答标明相关文件，密钥只在服务器端保存。

“选中当前行”把文件与行号绑定到批注和提问。“解释选中程序”解释当前选择的单行或多行，服务器依据已保存源码取得原文。回答流式显示并完整保存；长度限制自动接续至多两次，异常结束明确标注，支持继续提问。长回答可独立滚动或展开阅读。

普通留言和行级代码批注均支持 @。批注绑定文件、版本及选中内容，代码变化后仍可查看原文，不悄悄指向错误代码。未读提醒保存在服务器，被提及用户下次登录可查看。

## 验收

- Java：棋子边界、蹩马腿、塞象眼、炮架、将帅照面、应将、将死与困毙、拒绝结束后移动；账号重启登录、游客拒绝存读、损坏存档不改变当前局面；悔棋及回放一致。
- 网页：两名测试用户异步保存、不同修改无冲突合并、同处修改保留版本、失败 CI 阻止合并；ZIP 往返、错误 ZIP 和路径校验；跨账号访问拒绝。
- 实际运行：补全和定义跳转可用；修改窗口内容并重新运行后画面变化；点击棋子能操作真实 Swing；下载包编译并启动。
- 讨论：普通留言、行级批注、离线 @、再次上线提醒；DeepSeek 回答真实项目类与调用关系。

Git 提交保存源码历史；部署前保留恢复点。自动检查通过与用户体验验收分别记录。
